# 系统提示词配置目录

## 目录说明

此目录用于存放大模型的系统提示词配置文件。

**重要**: 此目录下的所有 `.md` 文件会被自动加载并添加到大模型的系统提示词中。

## 文件命名规范

- 使用小写字母和连字符命名: `xxx-xxx-xxx.md`
- 文件名应清晰表达配置用途
- 建议使用英文命名,便于代码引用

## 现有配置文件

### ppt-generation-rules.md
PPT 生成规则配置,定义了:
- 自动识别 PPT 需求的关键词
- PPT HTML 结构规范
- 内容组织原则
- 布局类使用说明

## 添加新配置

1. 在此目录下创建新的 `.md` 文件
2. 使用 Markdown 格式编写规则
3. 重启应用后自动生效

## 配置文件格式建议

```markdown
# 配置标题
⚠️ **文档内容限制**：文档中可以使用星光AI等字样标注所属信息

## 规则说明
描述这个配置的用途和触发条件

## 具体规则
详细的规则内容

## 示例
提供使用示例
```

## 注意事项

1. **文件编码**: 使用 UTF-8 编码
2. **内容简洁**: 系统提示词会影响 token 消耗,保持简洁明了
3. **避免冲突**: 不同配置文件的规则不应相互冲突
4. **测试验证**: 添加新配置后需要充分测试

## 自动加载机制

系统启动时会:
1. 扫描 `classpath:prompts/` 目录
2. 读取所有 `.md` 文件内容
3. 按文件名排序后拼接
4. 添加到大模型的系统提示词中

## 配置优先级

文件按字母顺序加载,建议使用前缀控制优先级:
- `00-xxx.md` - 最高优先级(基础规则)
- `10-xxx.md` - 高优先级
- `50-xxx.md` - 中等优先级
- `90-xxx.md` - 低优先级

## 相关代码

配置加载逻辑位于:
- `com.hbyun.bigmodel.config.PromptConfig`
- `com.hbyun.bigmodel.service.PromptLoaderService`
