## ⚠️ 注意事项

1. **账户编号唯一性**:
   - 测试数据中所有账户编号都是唯一的
   - 新增账户时避免使用已存在的编号

2. **银行账号格式**:
   - 遵循中国银行卡号规则(16-19位)
   - 不同银行的卡号前缀不同

3. **金额字段**:
   - ACCOUNT_BALANCE 和 CREDIT_LIMIT 单位为万元
   - 使用 DECIMAL(18,2) 类型存储

4. **状态枚举值**:
   - ETICKET_SYSTEM: ECDS, BECP, BANK_ETICKET
   - ACCOUNT_TYPE: ACCEPTANCE, DISCOUNT, REDISCOUNT, PLEDGE, CUSTODY, MARGIN
   - ACCOUNT_STATUS: NORMAL, FROZEN, CLOSED
   - SYNC_STATUS: SUCCESS, FAILED, PENDING

5. **日期格式**:
   - 使用 `TO_DATE('YYYY-MM-DD', 'YYYY-MM-DD')` 函数
   - 确保日期格式正确
