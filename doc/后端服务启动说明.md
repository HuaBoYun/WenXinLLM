# 后端服务启动说明

## 一、开始之前：认识这个后端工程

本指南写给刚拉取后端代码、想把服务跑起来的你。这个工程不是单个应用，而是一个多模块聚合仓库：一个 Eureka 注册中心、一个 API 网关，以及二十多个独立部署的业务服务模块。你不需要把它们全部启动——按第五章的顺序先起注册中心和网关，再按需启动你要开发或联调的业务模块即可。

先检查本机构建环境。打开命令行，依次执行以下命令并核对输出：

```bash
java -version   # 应输出 1.8.x
mvn -v          # 应输出 Maven 3.6+，且 Java version 为 1.8
```

**表 1-1 环境要求与自检命令**

| 组件 | 要求 | 自检命令 | 说明 |
|---|---|---|---|
| JDK | 1.8（必须） | `java -version` | 各模块 pom 均锁定 java 1.8，高版本会编译报错 |
| Maven | 3.6 及以上 | `mvn -v` | 项目自带 .mvn/wrapper 配置 |
| 数据库客户端 | 按模块二选一或多选 | — | 达梦 / MySQL / SQL Server，见第三章 |
| Redis | 3.x 及以上 | `redis-cli ping` | 多数模块依赖，默认 6379 端口 |
| 操作系统 | Windows / Linux 均可 | — | Windows 建议搭配 Git Bash |

代码目录与配套材料的对应关系：backcheck 为后端源码目录，每个子目录是一个可独立构建的 Spring Boot 模块；同级的 resources 文件夹存放离线依赖（前端下架 npm 包的离线副本 node_modules、本地 jar 仓库 repository）。各模块的第三方本地依赖放在各自 lib 目录中并以 system scope 引用，属于源码的一部分，不要删除。

## 二、第一步：配置 Maven 构建环境

如果本机首次使用 Maven 或下载依赖很慢，先在 Maven 的 settings.xml 中加入国内镜像（settings.xml 位于 Maven 安装目录的 conf 下，或用户目录 .m2 下）：

```xml
<mirror>
    <id>aliyunmaven</id>
    <mirrorOf>*</mirrorOf>
    <url>https://maven.aliyun.com/repository/public</url>
</mirror>
```

**预期结果：**任选一个模块（例如 hbyun-systemModule）执行 `mvn compile`，首次会下载大量依赖（几分钟到十几分钟），最终输出 BUILD SUCCESS。

### 安装离线 jar 到本地仓库（必做）

达梦驱动、计费/日志 SDK 等部分依赖不在任何远程仓库中，首次构建前必须先把 resources/repository 下的离线 jar 安装到本地 Maven 仓库。在 resources/repository 目录下执行一键脚本：

```bash
# Windows（CMD）
install-to-maven.bat

# Linux / macOS / Git Bash
bash install-to-maven.sh
```

脚本会安装以下 7 个坐标（与各模块 pom 的声明一一对应）：

| 坐标 | 对应 jar 文件 |
|---|---|
| dm.jdbc:DmJdbcDriver18:1.0 与 com.dameng:DmJdbcDriver18:1.0 | DmJdbcDriver18-1.0.jar |
| com.huabo.sdk.log:springboot-sdk-log:0.0.1-SNAPSHOT | springboot-sdk-log-0.0.1-SNAPSHOT.jar |
| com.huabo.sdk.billing:springboot-sdk-billing:0.0.1-SNAPSHOT | springboot-sdk-billing-0.0.1-SNAPSHOT.jar |
| e-iceblue:spire.doc.free:3.9.0 | spire.doc.free-3.9.0.jar |
| com.aspose.words:aspose-words:15.12.0 | aspose-words-14.9.0-jdk16.jar |
| com.hbyun:zhlabel-operator:2033-20220429 | LabelOperator2033_20220429_bytes.jar |

**预期结果：**脚本输出"全部离线 jar 安装完成"。此后各模块的 `mvn compile` 才能通过依赖解析。

## 三、第二步：准备数据库与中间件

不同模块使用不同的存储组件，启动前按你要运行的模块准备对应环境。各模块使用哪种数据库，以该模块 src/main/resources 下的 application-dev.yml 数据源配置为准；建表与初始化脚本同样位于模块 resources 目录（含 Flyway 格式的 db/migration 迁移脚本）。

**表 3-1 存储与中间件组件**

| 组件 | 默认端口 | 哪些模块在用 | 准备方式 |
|---|---|---|---|
| 达梦数据库（DM） | 5236 | 多数业务模块（jdbc:dm 链接） | 安装达梦或连接现成实例，默认账号 SYSDBA |
| MySQL | 3306 | 部分模块 | 创建库并执行模块自带建表脚本 |
| SQL Server | 1433 | 日志等模块 | 创建库并执行模块自带建表脚本 |
| Redis | 6379 | 多数模块（缓存、令牌） | 本机安装或指向内网 Redis |

你不需要一次准备所有组件。建议的最小启动组合是：达梦（或模块对应的数据库）+ Redis + 注册中心，即可支撑 systemModule 等核心模块启动联调。

## 四、第三步：填写被脱敏的配置（关键步骤）

这份代码在交付前做过统一的敏感信息脱敏：所有数据库密码、签名密钥、第三方令牌、服务器 IP 都被替换成了占位值。因此第一次启动前，你必须把配置改回你们环境的真实值，否则模块会在连接数据库时报认证失败。占位值与需要填写的内容对照如下：

**表 4-1 脱敏占位值对照**

| 占位值（你会看到的） | 含义 | 你需要填入 |
|---|---|---|
| password: REDACTED | 数据库 / FTP / 中间件密码 | 该环境真实的连接密码 |
| secret: 0000...（32 位 0） | 接口签名密钥（原 32 位十六进制） | 向管理员索取真实密钥 |
| RedactedKey12345 / RedactedHmac1234 | 余额计费 AES / HMAC 密钥（16 位） | 同上，注意保持 16 位长度 |
| 192.0.2.x（如 192.0.2.11） | 公司服务器公网 IP 占位 | 实际服务器的 IP 或域名 |
| 192.0.2.200 | 内网 IP 兜底占位 | 实际内网地址 |
| access_token=REDACTED | 用友云开放平台访问令牌 | 向管理员索取新令牌 |

配置文件的位置有规律：模块通用配置在 src/main/resources/application.yml，开发环境覆盖配置在同目录 application-dev.yml（启动时通过 spring.profiles.active=dev 生效），第三方对接参数在 resources/setting/*.properties（企业微信、蓝凌 OA、FTP 等）。绝大多数情况下你只需要改 application-dev.yml 里的数据源和 Redis 地址。

## 五、第四步：按顺序启动服务并验证

启动顺序有讲究：注册中心必须最先启动，其次是网关，各业务服务启动前需要先编译 springboot-hbyunutils 服务，发布到本地仓库之后各业务服务可以按需启动。所有命令都在对应模块目录下执行。

### 5.1 启动注册中心与网关

```bash
cd springcloud-hbfkEureka && mvn spring-boot:run
# 等待启动完成后，新开终端：
cd springboot-hbfkGatewayService && mvn spring-boot:run
```

**预期结果：**浏览器打开 http://127.0.0.1:8761 能看到 Eureka 管理页面；网关启动后监听 9000 端口，并出现在 Eureka 的实例列表中。

### 5.2 按需启动业务服务

按你要联调的功能选择模块，以系统设置模块为例：

```bash
cd hbyun-systemModule && mvn spring-boot:run
```

**表 5-1 主要模块与端口速查**

| 模块 | 端口 | 职责 |
|---|---|---|
| springcloud-hbfkEureka | 8761 | 注册中心（最先启动） |
| springboot-hbfkGatewayService | 9000 | API 网关（前端 /api 的代理目标） |
| hbyun-systemModule | 8763 | 系统模块：用户、组织、权限 |
| hbyun-contract | 8064 | 合同管理 |
| hbyun-finance | 8099 | 财务管理 |
| hbyunRiskControl | 8082 | 风险管控 |
| springboothbyunFinancialSharing | 8682 | 财务共享 |
| hbyunBigModelwen | 8380 | AI 大模型服务（前端 /bigmodel 后端） |
| springboot-hbyuncybermonitor | 8081 | 监控主服务 |
| springboot-hbyunFile / Log / Audit 等 | 8077 / 8066 / 8065 | 文件、日志、审计等支撑服务 |

验证方式：Eureka 页面的实例列表中出现对应服务名即注册成功；也可通过网关按路由前缀访问各服务接口（网关 application-dev.yml 内有完整的路由表，均指向 127.0.0.1 的各模块端口）。与前端联调时，前端开发服务器默认把 /api 请求代理到 http://127.0.0.1:9000，正是这个网关。

## 六、启动成功之后：几条重要提醒

1. 配置文件分环境：application.yml 是通用配置，application-dev.yml 是开发环境覆盖配置。不要在通用配置里写死环境相关的地址；切换环境用 spring.profiles.active 控制。

2. 日志输出在模块运行目录的 logs 下。仓库中原本携带的历史运行日志与编译产物（target、bin）已整体移出源码，不必寻找。

3. 使用 IDEA 开发时请安装 Lombok 插件并开启注解处理（工程根有 lombok.config），否则编译报大量 getter/setter 缺失。

4. 各模块 lib 目录下的 jar 是 system scope 依赖，升级时整组替换并同步修改 pom 中的版本与 systemPath。

## 七、启动失败？对照这张表排查

**表 7-1 常见报错与处理**

| 症状 | 原因与处理 |
|---|---|
| 启动报数据库认证失败 / 连接拒绝 | 第四步的 REDACTED 密码没有替换成真实值，或数据库地址/端口不对；检查 application-dev.yml |
| mvn 编译报 systemPath 找不到 | 没有从模块根目录构建，或 lib 目录不完整；确认 ${project.basedir}/lib 下的 jar 存在 |
| Maven 下载依赖很慢或超时 | 未配置国内镜像，按第二章配置阿里云镜像 |
| 服务启动了但 Eureka 页面看不到 | 检查 eureka.client.serviceUrl.defaultZone 是否指向 8761，且注册中心先于服务启动 |
| 端口冲突（Address already in use） | 修改该模块 application-dev.yml 的 server.port，同时注意网关路由表里的目标端口要同步改 |
| 前端能打开但所有接口 404 / 超时 | 网关（9000）没启动，或前端代理目标与网关地址不一致；对照网关路由表检查路径前缀 |
| 编译报 getter/setter 缺失 | Lombok 插件未安装或注解处理未开启 |
| 连接 Redis 报 NOAUTH / 密码错误 | Redis 密码同样被脱敏为 REDACTED，填回真实密码 |

## 八、附录：关于代码脱敏

本后端代码在交付前做过统一脱敏：数据库密码、签名密钥、第三方令牌、服务器 IP 等均替换为占位值；编译产物与运行日志已整体移出源码。

脱敏不影响代码逻辑，只影响需要连接真实环境的配置值。启动时遇到的连接类问题，优先对照第四章的占位值对照表逐项检查。
